# 期货K线回放复盘系统

一个纯前端实现的期货 K 线回放与模拟交易复盘工具。载入历史行情后，行情将逐根 K 线重新展开，你可以在"未知未来"的状态下做出开多、开空、平仓决策，系统按保证金与风险度实时核算账户，回放结束后自动生成完整的复盘报告，帮助你检验和改进交易策略。

支持 **1分钟 / 5分钟 / 30分钟** 三档 K 线周期随时切换，三个周期共享同一份 1 分钟基准行情，切换时回放位置、持仓与交易记录按真实时间自动对齐；还支持 **多窗联动模式**，1/5/30 分钟三窗同屏，十字光标、回放进度、交易标记跨窗同步。

整个项目零依赖、零构建，不需要 npm、打包器或后端服务，双击 `index.html` 即可运行。

## 操作说明

### 回放控制

- 点击「播放」或按空格键开始逐根回放，行情每次前进一根 K 线
- 速度下拉框提供 0.5x 至 32x 共 7 档，倍速越高揭示越快
- 「◀ ▶」按钮或左右方向键单步移动，「⏮ ⏭」或 Home / End 跳到首尾
- 拖动底部进度条可跳到任意位置；**向后拖动时，该位置之后产生的交易会被自动撤销**，账户与图表随之回滚
- 回放推进到最后一根时自动暂停并弹出复盘报告；点击「⏭」或按 End 手动跳到末尾同样会弹出报告

### 周期切换

- 点击回放控制条上的「1分 / 5分 / 30分」按钮，或按键盘 `1 / 2 / 3` 键
- 切换保持当前回放揭示时刻不变：例如 5 分钟周期下停在 10:35，切到 1 分钟后自动定位到 10:35 对应的 1 分钟 K 线，切到 30 分钟则定位到包含 10:35 的那根 30 分钟 K 线(进行中形态)；持仓、成本线、交易标记在任意周期下均按真实时间正确显示
- 大周期当前K线为"进行中"形态：只聚合已揭示的 1 分钟数据，随回放推进逐步成形(与行情软件一致)，**不会提前泄露未来走势**
- 聚合规则与行情软件一致：按真实交易时段(9:00-10:15 / 10:30-11:30 / 13:30-15:00)分段，每个时段从头开始每 N 分钟合并为一根，跨时段自动切分

### 多窗联动

点击回放控制条的「多窗联动」按钮或按 `M` 键，1 / 5 / 30 分钟三窗同屏上下纵向排列：

- **回放同步**：三窗始终停在同一揭示时刻，播放推进、单步、进度条跳转三窗联动
- **十字光标联动**：在任一窗口移动鼠标，另外两窗自动显示同时间竖线与同价格横线(弱化样式)，方便跨周期比对同一时刻
- **焦点窗口**：点击任意窗口(或按 1 / 2 / 3)切换焦点，焦点窗口高亮边框标识；**回放步进粒度由焦点周期决定**——5 分钟焦点每次前进一根 5 分钟 K 线，1 分钟窗随之跳 5 根，30 分钟窗的当前 K 线逐步成形
- **标记与成本线**：开平仓标记、多空成本线按时间映射到所有窗口，任意窗都能看到完整交易轨迹
- **状态无损**：单图 ↔ 联动模式随时切换，持仓、交易、回放进度全部保留
- 各窗口表头实时显示最新价与涨跌幅(相对各自周期前一根收盘)，三窗价格始终一致

### 交易操作

所有成交以当前 K 线的收盘价执行：

1. 在「手数(手)」输入框填写手数，或使用快捷仓位按钮(25% / 50% / 75% / 全仓)，按可用资金能支撑的最大手数折算
2. 「开多 (B)」建立多头仓位，「开空 (S)」建立空头仓位，两者可同时持有(双向持仓)
3. 「平多 (L)」了结多头，「平空 (C)」了结空头，「全平 (X)」一键了结全部持仓
4. 成交后图表出现标记：多开/空平(买方向)为 K 线下方向上箭头，空开/多平(卖方向)为 K 线上方向下箭头；持有多头或空头时图表分别显示金色/浅蓝成本虚线
5. 风险度达到 100% 时系统自动以当前价全部平仓(可在设置中关闭)

### 复盘报告

回放结束自动弹出，也可随时点击「复盘报告」按钮查看。报告包含：

- 期末账户权益、总收益率
- 买入持有对比(与从起点一直持有多头到当前的收益比较，衡量主动交易是否跑赢躺平)
- 交易次数与平仓次数(平多 / 平空分开统计)
- 胜率、盈亏比、平均盈利 / 平均亏损
- 最大回撤(百分比与金额)
- 累计手续费
- 资产曲线图(含初始资金基准线)

点击「导出记录」可将全部交易明细下载为 CSV 文件(时间/操作/价格/手数/成交额/手续费/平仓盈亏)，方便在 Excel 中进一步分析。

### 账户核算模型

- **动态权益** = 现金 + 浮动盈亏(现金已含全部已实现盈亏与手续费)
- **占用保证金** = 多头保证金 + 空头保证金(按各自开仓均价计)
- **可用资金** = 动态权益 - 占用保证金
- **风险度** = 占用保证金 / 动态权益，达到 100% 触发强平
- 多头浮动盈亏 = (现价 - 多头均价) × 手数 × 乘数；空头浮动盈亏 = (空头均价 - 现价) × 手数 × 乘数
- 同方向加仓采用移动加权平均成本；最大可开手数按"保证金 + 手续费均需可用资金覆盖"计算

### 品种预设与设置应用

「设置」弹窗顶部的品种预设下拉框包含两部分：

- **自定义参数(保持当前品种)**：仅应用弹窗中的参数，行情数据不变
- **10 个品种预设**：选中后自动填充乘数/保证金率/手续费，可再手动微调

应用规则：

- 选择了**与当前行情不同的品种**并应用：切换至该品种的随机行情(价格量级、最小变动价位匹配该品种)，顶栏品种名称与合约代码同步更新，账户与回放进度全部重置
- 选择「自定义参数」或**与当前相同的品种**并应用：保留当前行情数据，仅重置账户(交易清空、回到起点)
- 手动微调的参数优先生效：选择预设后又手动修改了乘数/保证金率/手续费，应用时以修改后的值为准，不会被预设值覆盖
- 打开设置时下拉框自动定位到当前行情对应的品种(导入的自定义数据显示为「自定义参数」)
- 任何设置应用后参数都会保存到浏览器本地，下次打开自动恢复

## 时间回溯机制

这是复盘功能的核心设计：每笔交易都记录其发生的真实时间。当回放位置向后跳转时(拖动进度条、按 Home、单步后退、切换到更早结束的周期边界)，系统自动执行两步操作：

1. 保留回放时刻之前的交易记录，撤销之后的所有交易
2. 基于保留的交易从初始资金开始按序重放，重建完全一致的账户状态(现金、多空持仓、成本、已实现盈亏、资产曲线)

因此可以放心地反复回到某个历史位置，尝试不同的决策路径，对比同一行情下不同操作的结果差异。

## 数据导入

点击「导入数据」支持 CSV 与 JSON 两种格式，文件名会作为品种名称。导入的 K 线作为 **1 分钟基准数据**，1/5/30 分钟周期均由它聚合而来。解析时自动进行数据清洗：过滤无效行、修正高低价、按时间升序排列、同一时间去重(后者覆盖前者)。有效 K 线数量不少于 30 根才能回放。

### CSV 格式

自动检测分隔符(逗号 / 制表符 / 分号)，首行有表头时按关键字自动定位列，无表头时按「时间,开,高,低,收,量」顺序解析：

```csv
time,open,high,low,close,volume
2026-08-24 09:00,3600,3612,3598,3605,12600
2026-08-24 09:01,3605,3608,3596,3599,8400
2026-08-24 09:02,3599,3610,3597,3608,9800
```

表头关键字不区分大小写，中英文均可：时间列 `date/time/日期/时间`，开 `open/开盘`，高 `high/最高`，低 `low/最低`，收 `close/收盘`，量 `volume/vol/成交量`(可省略)。

### JSON 格式

支持三种结构：

```json
// 结构一:对象数组(字段名 time/date/day/timestamp 均可,量 volume/vol 均可)
[
  { "time": "2026-08-24 09:00", "open": 3600, "high": 3612, "low": 3598, "close": 3605, "volume": 12600 },
  { "time": "2026-08-24 09:01", "open": 3605, "high": 3608, "low": 3596, "close": 3599, "volume": 8400 }
]

// 结构二:二维数组 [时间, 开, 高, 低, 收, 量]
[
  ["2026-08-24 09:00", 3600, 3612, 3598, 3605, 12600],
  ["2026-08-24 09:01", 3605, 3608, 3596, 3599, 8400]
]

// 结构三:嵌套在外层对象的 data / bars / klines 字段中
{ "code": "RB2612", "name": "螺纹钢", "data": [ { "time": "2026-08-24 09:00", "open": 3600, "high": 3612, "low": 3598, "close": 3605 } ] }
```

### 日期与数值兼容

- 日期：毫秒/秒时间戳、`2026-08-24 09:00`、`2026-08-24`、`2026/08/24`、`20260824`，以及其他可被标准 `Date.parse` 识别的写法；带时间(时:分)的行按分钟级 K 线处理，纯日期的行按日 K 处理
- 数值：支持千分位逗号(如 `1,200,000`)与中文单位后缀(如 `86万`、`1.2亿`)

## 模块设计要点

**data.js (KData)** 维护一份 1 分钟基准 K 线，`aggregate(baseBars, n)` 按真实交易时段将其聚合为任意分钟周期；`generateRandomMinuteBars` 按国内白盘时段(9:00-10:15 / 10:30-11:30 / 13:30-15:00)生成带趋势切换与波动聚集的随机行情，内置 10 种品种的价格量级与最小变动价位参数。

**chart.js (KChart)** 接收当前周期的 K 线数据，但仅绘制到 `setCursor(i)` 指定的位置，实现"未来行情已加载但不可见"。`setLiveBar` 支持用截断聚合的"进行中K线"替换最后一根(大周期回放逐步成形、不泄露未来)，位置切换时自动恢复完整聚合；`setLinkedHover` / `onHoverChange` 提供多窗联动的十字光标同步能力。多空两条成本虚线价格接近时标签自动错位；同一根 K 线上的多个开平仓标记水平错开。Y 轴始终按可见区间自适应，滚轮缩放以鼠标位置为锚点。绘制调度 rAF 优先，rAF 受限的环境下自动回退到定时器兜底。

**player.js (ReplayPlayer)** 用定时器驱动(不依赖 requestAnimationFrame，后台标签页与受限环境也能推进)，按速度倍率折算每根 K 线的时间间隔，通过 `onTick / onState / onEnd` 三个回调与外界解耦，本身不接触任何 DOM。

**trading.js (FuturesSim)** 是一个纯状态机，提供 `openLong / openShort / closeLong / closeShort / closeAll / checkLiquidation / equity / available / maxOpenLots` 等方法，双向持仓、保证金、按手手续费、风险度判断全部封装在内部，可脱离页面单独测试。

**review.js (KReview)** 的 `computeStats` 接收交易数组与资产曲线，输出胜率、盈亏比、最大回撤、买入持有对比、平多/平空次数等指标；`drawEquityCurve` 用 Canvas 绘制带基准线的资产曲线；`tradesToCSV` 生成带 BOM 的 UTF-8 CSV，Excel 打开不乱码。

**app.js** 负责装配与联动：维护 1 分钟基准数据、三周期聚合缓存与全局"揭示时刻"(`lastTime`)，周期/焦点/模式切换均保持揭示时刻不变(pendingAnchor 机制)，仅重映射播放位置，时间不回退、交易不回溯；大周期最后一根 K 线通过 `buildLiveBar` 截断聚合为进行中形态；多窗联动模式下三窗光标、标记、成本线按时间统一映射；回放位置变化时同步所有窗口与面板并检查强平；回溯时按记录重放交易；设置读写 localStorage。

## 二次开发建议

- 接入真实行情：在 `data.js` 中新增一个从接口拉取 1 分钟 K 线并调用 `parseJSON` 规范化的函数即可(注意浏览器跨域限制，需要代理或 CORS 支持)，导入后 5/30 分钟周期自动聚合
- 新增周期：在 `index.html` 的周期按钮组与 `app.js` 的周期快捷键中各加一项即可，聚合逻辑天然支持任意 N 分钟
- 新增技术指标：在 `chart.js` 的均线计算处扩展 MACD、KDJ 等，指标计算逻辑建议放在独立模块
- 添加交易策略回测：`FuturesSim` 与 `ReplayPlayer` 均已与 UI 解耦，可以写一个自动策略在无界面环境下批量回放，并复用 `KReview.computeStats` 输出报告

## 已知边界

- 单次回放建议数据量在数万根 1 分钟 K 线以内，数据量过大时 Canvas 缩放平移可能出现明显卡顿
- 双向持仓采用"多空两条腿独立核算"，不做自动对冲(锁仓不减免保证金)；分批建仓采用加权平均成本，不追踪每笔明细
- 刷新页面后交易记录与回放进度不会保留，仅「设置」中的交易参数会持久化
